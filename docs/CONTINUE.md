## Первый запуск (Windows / PowerShell)

Установить Git и **JDK 21** (полный JDK, не только JRE). Доступ к репозиторию GitHub нужен под своим аккаунтом, если репозиторий закрыт. Отдельный Gradle, Python, Minecraft Launcher, NeoForge Installer и старые локальные кэши для разработки не нужны: Wrapper загрузит Gradle и зависимости. Первый запуск требует интернета и свободного места для зависимостей.

```powershell
git clone --branch phase1 https://github.com/D1pex2/Minetorio.git
cd Minetorio
java -version
.\gradlew.bat --version
.\gradlew.bat test runGameTestServer build --console=plain
.\gradlew.bat runClient
```

Обе команды проверки версии должны показывать Java 21. Если выбрана другая Java, установить `JAVA_HOME` в путь **своего** JDK 21 и добавить `$env:JAVA_HOME\bin` в PATH текущего терминала. Путь `C:\Users\kirill\.jdks\...` со старого компьютера копировать не нужно. В IDE также выбрать JDK 21 и Gradle Wrapper.

На Linux/macOS использовать `./gradlew` вместо `.\gradlew.bat` (при необходимости `chmod +x gradlew`). Сборка мода: `build/libs/minetorio-0.8.0.jar`. Сгенерированные ресурсы уже в Git: запускать генераторы арта перед игрой не требуется.

## Universal Modder — только для этого проекта

Глобально устанавливать плагин на новом ПК **не нужно**. В репозиторий включены 13 навыков Universal Modder 0.2.0 в `.agents/skills/universal-modder-*`. После клонирования открыть папку Minetorio в Codex и начать новый чат, чтобы он обнаружил проектные навыки. Это локальный пакет навыков и CLI, а не глобальная установка плагина.

Исходники CLI и база знаний лежат в `tools/universal-modder`; происхождение, лицензия MIT и команды необязательной установки Python-зависимостей в локальную `.venv` — в [UPSTREAM.md](../tools/universal-modder/UPSTREAM.md). Для чтения навыков и сборки Minetorio эта установка не требуется. MCP/fal, ключи, автозапуск и глобальные настройки не добавлены. Внешние инструменты для конкретных операций настраиваются отдельно по необходимости.

## Миры и демо

Новый мир по умолчанию использует Наувис. Для быстрого осмотра распаковать **demo/Minetorio-Demo.zip** в `run/saves/`: непосредственно внутри папки мира должен лежать `level.dat`. Затем запустить `runClient` и открыть этот мир. Демо — витрина с искусственным снабжением; это не прохождение выживания. Детали: [demo-world.md](demo-world.md).

**Личные сохранения в Git не входят.** Для продолжения именно своего мира отдельно перенести папку нужного мира из старого профиля, пока игра закрыта. Последний профиль этой сессии — `.superpowers/playtest-fixes-client/saves`, более ранний — `.superpowers/playtest-world-ui/saves`; обычный профиль — `run/saves`. Копировать выбранную папку целиком (включая `data`, `region`, данные игрока и модовые данные), на новом ПК положить в `run/saves`. Не заменять личный мир демо-архивом. Папки `.superpowers`, `.claude`, `build`, `.gradle` и старый JDK переносить для сборки не требуется.

В ветку объединены базовый завод, рудные поля и карта, чертежи и дроны, нефтехимия, генерация Наувиса, свой инвентарь и окна машин. Захват окна через Computer Use в этой сессии не работал, успешный визуальный прогон не заявлен. Историческая проверка предыдущей передачи: **565 юнит-тестов, 332 обязательных GameTest, сборка успешна** (2026-10-29). Подход к дробному stop идет последовательными штатными шагами с plan/commit, без присваивания позы или скорости. Финальная проверка: 739 юнит-тестов, 366 обязательных GameTest и сборка прошли.

В оригинальной Factorio 1.1.110 на одном локомотиве подтвержден интервал ожидания в 60 тиков. Центр локомотива останавливался на 3 плитки до центра присоединенного рельса; внешняя сцепка и внутренний elapsed напрямую не измерены. Station.stop в нашем core остается travel-directed внешней сцепкой. World adapter Task7 должен преобразовать физическую позицию станции в этот target. Подбор дробного throttle и UUID tie-break остаются явными моделями Minetorio, а не доказанными формулами закрытого движка.
