# Авторская музыка

Обычная музыка Minecraft отключена. Мод не содержит треков Factorio и не подменяет их чужой музыкой.

Для своей музыки добавьте ресурс-пак со звуковым событием `minetorio:music.nauvis`.
Файлы OGG Vorbis размещаются в `assets/minetorio/sounds/music/`, например `nauvis_01.ogg`.
В `assets/minetorio/sounds.json` укажите:

```json
{
  "music.nauvis": {
    "replace": true,
    "sounds": [
      {"name": "minetorio:music/nauvis_01", "stream": true}
    ]
  }
}
```

Событие может содержать несколько треков: движок выбирает их по весам. После входа в мир
первая попытка воспроизведения происходит через 10 секунд, между треками — пауза около минуты.
Без добавленных треков звучат обычные звуки мира и машин. Громкость регулируется ползунком «Музыка».
При выходе из мира текущий трек останавливается. Пауза игры приостанавливает отсчёт интервала.
