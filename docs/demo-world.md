# Демо-мир Minetorio (этап 1)

Витрина, где за пару минут можно обойти все механики этапа 1 в работе: ленты, манипуляторы,
добыча, плавка, энергия, сборка, исследования и ручной крафт.

## Вариант 1: готовый мир

Сохранение лежит в `demo/Minetorio-Demo.zip` (суперплоский творческий мир, витрина уже построена).

1. Распакуйте архив в папку сохранений: для `./gradlew runClient` это `run/saves/`
   (должно получиться `run/saves/Minetorio-Demo/level.dat`), для обычного лаунчера — `.minecraft/saves/`.
2. Запустите игру с модом (`./gradlew runClient`), «Одиночная игра» → **Minetorio Demo**.
3. Вы появитесь у входа (западный конец дорожки). Всегда день, мобов и погоды нет.

В готовом мире витрина уже проработала около 45 секунд: исследование `automation` выбрано и почти
готово (8 из 10 единиц), после него автовыбор возьмёт следующее на красной науке (см. ниже).

## Вариант 2: построить командой

Лучше всего — в новом **суперплоском творческом** мире с читами:

```
/minetorio demo
```

> **Внимание.** Команда **уничтожает всё** в квадрате 96×96 вокруг вас на 20 блоков вверх от пола:
> постройки, сундуки вместе с содержимым, мобов (кроме игроков). Не запускайте её рядом со своей базой.
> «Бесконечные» сундуки витрины — это творческий чит: в мире выживания они дают ресурсы даром.

- Нужен уровень прав 2 (оператор / читы включены).
- Строит витрину 96×96 вокруг игрока: площадка расчищается (20 блоков вверх) до ровного пола
  из травы, игрок переносится ко входу и смотрит на восток вдоль дорожки.
- С сервера/консоли: `/minetorio demo <x> <y> <z>` — координаты «ног» (пол — блок ниже),
  витрина строится вокруг этой точки, игрока не переносит.
- Только Верхний мир (залежи есть только там).
- Повторный запуск на том же месте перестраивает витрину с нуля.
- Если постройка не удалась (например, что-то мешает поставить машину), команда сообщит причину и
  ничего не зарегистрирует; постройку можно запустить ещё раз.
- В ответ команда пишет, какое исследование сейчас идёт.

### Выключить демо

```
/minetorio demo off
```

Останавливает всё «демо-волшебство» в этом мире: сундуки больше не пополняются и не очищаются,
ленты не наполняются, автовыбор исследований выключен, демо-залежь удалена (буры на ней
останавливаются). Сами блоки витрины остаются — их можно сломать вручную.

Примерно через 30 секунд после постройки движение видно на каждой остановке (паровой двигатель
разгоняется за ~5 с, первые пластины выходят из печи примерно через 15–20 с).

Совет: `/time set day` и `/gamerule doDaylightCycle false`, если мир не суперплоский демо-мир.

## Что где

Дорожка идёт с запада на восток. Севернее дорожки остановки 1–4, южнее — 5–8 (идите на восток
по северной стороне и возвращайтесь по южной). У каждой остановки табличка (en/ru — по языку клиента).
Вдоль северного края дорожки стоят столбы: провода тянутся от паровой станции ко всей витрине.

| № | Остановка | Что показывает |
|---|---|---|
| 1 | **Ленты** | Жёлтая, красная и синяя ленты рядом (видна разница скоростей 15/30/45 предм./с). Вторая линия: два изгиба, подача сбоку (медь ложится на ближнюю полосу), подземная лента под каменной стеной, разделитель на две ленты. Ленты наполняются «бесконечными» источниками и заканчиваются сундуками, которые очищаются. |
| 2 | **Манипуляторы** | Все 4 вида: твердотопливный носит уголь (и сам им топится), обычный — сундук → лента → обычный → сундук, длинный — через пустую клетку (дальность 2), быстрый — сундук → сундук. |
| 3 | **Добыча** | Залежь железа (пол из блоков необработанного железа, 1 000 000 руды). Твердотопливный бур → сундук; его кормит углём твердотопливный манипулятор. Электробур → лента на плавку. Сканер в рамке и в сундуке: возьмите и нажмите ПКМ по земле на залежи. |
| 4 | **Плавка** | Лента с рудой → манипулятор → каменная печь (уголь подаёт твердотопливный манипулятор) → манипулятор → сундук с железными пластинами. |
| 5 | **Энергия** | Вода → насос → трубы → бойлер (уголь подаёт манипулятор) → 2 паровых двигателя подряд → столбы с проводами. |
| 6 | **Сборка** | Лента с железом и медью. Сборщик 1 делает шестерни → сундук → сборщик 2 делает красную науку (шестерня + медь с ленты) → сундук. |
| 7 | **Исследования** | 2 лаборатории, красную науку им подают манипуляторы из общего сундука. Текущее исследование — `automation`. Нажмите **Y**, чтобы открыть дерево. |
| 8 | **Ручной крафт** | Сундук с материалами (пластины, булыжник, палки, уголь). Возьмите материалы и нажмите **R**. |

## Как это устроено (только для демо)

- **Демо-залежь.** Железная залежь — «размещённая» (`Deposits.placeDemoDeposit`): хранится в
  сохранении мира (`minetorio_deposits`, id от −1000 вниз), не зависит от сида и перекрывает
  сгенерированные залежи внутри своего круга. Сканер и буры видят её как обычную.
- **Бесконечные источники.** Это сундуки с именем «Демо-источник» / «Демо-сток» и ленты, записанные
  в `minetorio_demo` (`DemoSavedData`). Раз в секунду сундуки-источники пополняются (уголь для всех
  топливных линий, пластины, красная наука, сканеры, материалы для крафта), стоки на концах лент
  очищаются, а выходные сундуки (руда бура, пластины из печи, шестерни, красная наука) обрезаются до
  одного стака: выход всегда виден и линии никогда не забиваются. На начало лент-источников каждый тик
  кладётся предмет, если есть место. Поэтому витрина работает часами без присмотра.
- Трогаются только сундуки, которые поставила витрина. Если сундук сломать или заменить своим
  (или убрать ленту), запись забывается навсегда — ваш сундук не будет ни пополняться, ни очищаться.
- **Исследования.** Пока автовыбор включён, при пустом текущем исследовании выбирается следующее,
  которому нужна только красная наука (`automation` → `logistics` → `fast_inserter` →
  `logistic_science_pack`, ~10 минут); потом лаборатории останавливаются. Как только любой игрок сам
  выберет исследование (Y), автовыбор выключается навсегда.
- В мирах, где команду не запускали, ничего из этого не существует и не работает.

## Как пересобрать `demo/Minetorio-Demo.zip`

Архив сделан так (без выделенного сервера, EULA не нужна):

1. Взять `level.dat` суперплоского творческого мира с читами (например, мира GameTest-сервера
   `run/world/level.dat`), переименовать мир, убрать экспериментальные наборы данных, поставить
   точку появления у входа (−47, −60, −1), выключить смену дня, погоду и мобов.
2. Положить его в `run/saves/Minetorio-Demo/` вместе с датапаком, у которого функция `#minecraft:load`
   выполняет `minetorio demo 0 -60 0`.
3. Открыть мир в `./gradlew runClient`, дать поработать ~2 минуты, закрыть окно (мир сохраняется).
4. Удалить датапак и упаковать папку мира (без `session.lock`).
