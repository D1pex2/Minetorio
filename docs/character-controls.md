# Character inventory and shortcuts

- Press **E** or **R** to open the character window. The left panel contains 80 real inventory slots; the right panel contains hand-crafting recipes and the queue. The upper buttons open personal logistics and production statistics.
- The first small slot below the shortcuts is the character's locked tool. The next slot is recoverable logistics trash: place ordinary items there for available logistics robots to collect when a storage chest is reachable. Items with extra data remain in the slot.
- The shortcut row below the inventory remembers item types, not extra stacks. Pick up an item in the inventory and left-click a shortcut to assign it; right-click a shortcut to clear it. Left-click an assigned shortcut with an empty cursor, or press **1–9** or **0** in the world, to select that item from the inventory. The icon stays dark when the item runs out.
- Press **X** in the world to switch the active shortcut row. Use the **+** button in the character window to cycle the number of visible rows from one to four. These keys can be reassigned in Minecraft controls.
- A selected shortcut moves an existing stack into the selected hand slot; it does not create another stack. If the item has run out, selecting it empties the hand; when all 80 slots are full, the physical stack stays safely stored and is not used or dropped as the missing item.


Creative mode uses the same **E/R** character window. The **Creative catalog** button opens the separate creative item catalog; it never completes survival research. Drag a carried item onto a shortcut, or click it while carrying an item, to remember that type. **1–9 / 0** select all ten columns. The mouse wheel changes shortcuts in ordinary view; in the top-down building camera it keeps zooming. The current shortcut is outlined.

The mining tool appears in the empty main hand during mining/swing animations in first and third person; this is a visual representation of the locked tool and never creates another inventory item.

**X** cycles only the configured visible rows (1–4); hidden saved bindings are retained. The custom HUD places health above all visible shortcut rows and hides vanilla food/XP widgets. Alt mode adds a readable recipe/status panel for the targeted machine. Crafting tooltips and machine recipe previews show ingredient/product icons; previews do not create inventory items.
