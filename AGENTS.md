# Работа над Minetorio

Пользователь — программист 1С; общаться по-русски, объяснять результат простыми словами.

Перед продолжением прочитать `docs/CONTINUE.md`, `docs/roadmap.md` и `docs/superpowers/plans/2026-10-29-minetorio-rocket-and-war.md`, затем проверить текущий код и `git status`. Рабочая ветка на момент передачи — `phase1`.

Механики, рецепты и исследования брать из Factorio **1.1.110**. Переход на 2.0/Space Age отложен; исключение — уже согласованные сегменты жидкостей. Старые ограничения «без кусак и военного» отменены: полная цель включает прогрессию до ракеты, врагов и военную часть.

Не путать план с реализованными возможностями. Не выдавать автотесты за визуальный плейтест. Не зависеть от локальных `.superpowers`/`.claude` и абсолютных путей старого компьютера. Сборка и проверки должны работать через репозиторный Gradle Wrapper с JDK 21.

Обычная проверка: `./gradlew test runGameTestServer build --console=plain` (на Windows `./gradlew.bat`). Прогоны Gradle выполнять последовательно, пользовательские миры сохранять.

Universal Modder доступен как проектные навыки в `.agents/skills/universal-modder-*`, CLI и база знаний — в `tools/universal-modder` (см. `UPSTREAM.md`). Глобально плагин не устанавливать. Использовать локальные навыки по задаче; внешние сервисы и инструменты не настроены автоматически.
